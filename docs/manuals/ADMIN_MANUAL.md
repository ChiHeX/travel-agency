# 后台操作手册

本手册与[用户端操作手册](USER_MANUAL.md)共同构成操作说明。课程演示数据和沙箱交易不代表真实经营数据。

## 1. 登录与权限

使用分配的账号登录；ADMIN／STAFF 从经营后台操作，GUIDE 使用 `/guide/dashboard` 和 `/guide/departures`。
普通用户不能进入后台。没有入口或跳回首页时，先确认账号类型，不要使用其他人的账号绕过限制。

| 操作 | ADMIN | STAFF | GUIDE |
|---|---|---|---|
| 经营统计、线路、每日行程、团期、景点、酒店维护 | 可以 | 可以 | 不可以 |
| 分配团期导游、修改导游基础资料 | 可以 | 可以 | 不可以 |
| 创建、停用、恢复导游账号 | 可以 | 不可以 | 不可以 |
| 订单查询与确认、退款审核、评价／咨询／攻略管理 | 可以 | 可以 | 不可以 |
| 用户、工作人员管理与操作日志 | 可以 | 不可以 | 不可以 |
| 导游游客名单与行程操作 | 遵守现有接口归属限制 | 不可以 | 仅本人负责团期 |

角色固定为 USER、STAFF、GUIDE、ADMIN；不提供角色编辑器、角色升级或管理员重置他人密码。
ADMIN 由初始化或受控运维配置提供，普通注册只创建 USER。所有人只能按用户端既有规则操作个人业务。

## 2. ADMIN：工作人员与用户管理

1. 打开“内部人员权限”（`/admin/staff`），按姓名、工号、手机号及状态查询，使用翻页查看后续记录。
2. 点击“新增员工”，填写登录账号、初始密码、姓名、工号，以及可选的手机号、部门、岗位。
   账号为 3–32 位字母、数字、下划线；密码为 8–72 个 Unicode 字符且 UTF-8 不超过 72 字节。
3. 保存后创建固定 STAFF 账号；没有角色选择器。遇到账号或工号重复，修改相应输入后重试。
4. 点击“编辑”修改姓名、手机号、工号、部门、岗位。用户名只读，账号绑定、密码、角色均不可修改。
5. 停用或恢复前核对人员并确认；取消不会提交。停用会撤销登录访问能力，恢复不会重置密码。
6. 打开“注册用户账户”（`/admin/users`）查询用户、查看基础资料、停用或恢复账号；不提供密码编辑。
7. 在“操作日志”（`/admin/logs`）按模块查询重要业务操作。排查问题时提供时间、对象号及错误提示，避免传播敏感数据。

## 3. STAFF／ADMIN：经营后台

### 线路、行程、资源与团期

1. 在线路管理维护旅游产品及每日行程；酒店和景点是行程资源，不是独立售卖库存。
2. 在团期列表按线路、导游、状态、出发日期查询；候选项加载失败时点击“重试”。
3. 创建具体出发日期、价格、容量和导游安排；新团期为草稿，开放报名后才能售卖。
4. 编辑冲突时重新读取最新资料再决定修改，不要反复提交旧版本。历史订单价格与出行人快照不随资料编辑变化。
5. STAFF 可以编辑导游资料和分配团期；创建或启停导游账号必须由 ADMIN 操作。

### 订单确认与退款

1. 在订单管理按订单号、联系人、手机号或实际业务状态查询，打开详情核对线路、团期、金额、支付和出行人资料。
2. 仅对待确认报名的订单点击“确认报名”，确认框取消时不提交。服务端会再次核验状态、资料与名额。
3. 在退款审核打开详情，核对申请金额、原因与历史审核记录。填写 1–500 个字符的真实审核意见后同意或拒绝。
4. **退款显示 PROCESSING／结果待确认时，钱可能已退出，不能拒绝、恢复订单或另建退款出款请求。**
   使用“重试确认”，后端沿用同一出款请求号；持续失败时保留退款单号并交由交易模块负责人排查。
5. 接口报错后先刷新状态；错误提示不等于没有发生出款。只有退款记录明确成功才按完成处理。
6. 订单筛选不提供保留值 REFUND_PROCESSING／REFUND_REJECTED。退款单的 PROCESSING／REJECTED 与审核意见在退款记录中查看。

### 内容运营

评价管理可隐藏或恢复评价；咨询管理可查看、回复和关闭工单；攻略管理支持草稿、编辑、发布及下线。
编辑攻略时保留正确的关联景点，只有明确取消关联才选择“不关联”。切换工单前注意尚未发送的输入不会跨工单保留。
地点指南通过多个景点编排展示，公开内容需发布后才可见。不要录入虚构经营统计或未标注的演示资料。

## 4. GUIDE：本人团期

1. 登录后进入导游工作台，查看本人负责的团期；按分类与分页查找行程。
2. 打开团期详情核对日期、每日安排和脱敏游客名单。不能通过替换 ID 访问他人团期。
3. 允许开始的团期显示“开始行程”；行程中显示“标记行程已结束”。核对后确认，取消不提交。
4. 名单仅供带团使用，不应导出、传播完整身份信息。账号无导游档案或无归属时，联系 ADMIN 核查分配。

## 5. 常见错误与处理

| 现象 | 处理 |
|---|---|
| 列表加载失败 | 点击重新加载，勿把失败当作空列表 |
| 没有符合条件的数据 | 清空搜索或状态／日期条件，再查看其他页 |
| 账号／工号重复 | 修改对应字段；不要反复点击保存 |
| 422 字段错误 | 按提示检查必填、长度、字节限制；资料编辑不能夹带账号、密码、角色字段 |
| 409 状态或版本冲突 | 刷新最新数据后重新核实，不强行覆盖或重复审核 |
| 401 登录失效 | 重新登录；停用账号需 ADMIN 恢复状态，不是重置密码 |
| 403 无权操作 | 核对角色和团期归属，不申请临时绕过后端权限 |
| 退款结果未确认 | 保留单号，只用安全重试，不拒绝已发出的出款 |

个人报名、支付、取消、评价、咨询和本人改密步骤见[用户端操作手册](USER_MANUAL.md)。
