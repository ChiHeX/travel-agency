# 行迹旅行用户端操作手册

适用对象：浏览线路、报名跟团游及管理个人订单的普通用户。  
适用版本：本手册编写时的用户端功能，界面入口与可操作项目以实际部署版本为准。

> 本项目为课程演示系统。支付宝使用沙箱环境，本地模拟支付仅用于开发测试，不涉及真实资金。演示线路、订单及评价等测试数据不代表真实旅行社经营情况。

## 1. 快速上手

首次报名可按以下顺序操作：

1. 打开项目提供的网站地址，注册并登录账号。
2. 从“搜索”或“路线”查找想参加的行程。
3. 打开线路详情，阅读每日行程、费用说明及预订须知。
4. 选择合适的团期，核对日期、价格与剩余名额，点击“立即报名”。
5. 填写人数、联系人及每位出行人的资料，提交并进入付款页。
6. 核对订单摘要，按当前环境支持的方式完成测试付款。
7. 在订单详情查看状态；显示“待确认”时，等待旅行社审核报名。
8. 报名确认后查看行程安排；行程完成后可发布评价。

**线路与团期的区别：** 线路是旅游产品和行程方案；团期是该线路的一次具体出发安排。不同团期的日期、成人价、儿童价及名额可能不同，报名时需要选择具体团期。

## 2. 页面导航与地图操作

### 2.1 主要入口

| 入口 | 用途 |
|---|---|
| 搜索 | 按关键词查找线路，查看热门目的地及线路分类 |
| 路线 | 按出发城市、目的地、天数、月份等条件筛选线路 |
| 指南 | 浏览城市与发布者推荐的地点，进一步查找途经线路 |
| 登录／我的 | 登录账号或进入个人资料及用户中心 |
| 消息 | 登录后查看站内通知，也可从用户中心进入 |

用户中心顶部的“设置”导航包含：个人资料、我的订单、常用出行人、我的收藏、我的评价、消息、咨询、账号安全。窄窗口下可横向滑动该导航查找入口。

### 2.2 地图与内容面板

1. 拖动地图查看其他区域，使用鼠标滚轮或地图缩放控件调整比例。
2. 浏览指南或线路时，地图会根据当前内容显示相应区域或行程地点。
3. 点击详情页的返回按钮，可回到进入该页面之前的页面；关闭按钮用于关闭当前内容面板。
4. 在支持分享的详情页点击分享图标，可使用浏览器分享功能或复制链接。若浏览器不支持，可复制地址栏链接。

窄窗口下，地图内容面板位于屏幕底部。按住顶部横条上下拖动，可连续调整面板高度，松手后停在当前位置；面板内容可单独滚动。横条获得键盘焦点后，可用上下方向键调整高度。

### 2.3 查看无数据或错误提示

“暂无数据”表示当前条件下没有可展示内容。可放宽筛选条件后再试。出现“加载失败”时，点击页面提供的“重新加载”或“重试”；不要将加载失败理解为没有线路或没有订单。

## 3. 注册、登录与退出

### 3.1 注册账号

1. 点击“登录”，在登录页选择“创建一个账号”。
2. 填写用户名、密码和昵称；手机号及电子邮箱按需要填写。
3. 用户名按页面提示使用 4–32 位字母或数字；密码至少 8 位。
4. 点击注册按钮。成功后系统进入首页。

用户名已存在或资料格式不正确时，按页面提示修改后重新提交。

### 3.2 登录

1. 打开“登录”页面。
2. 输入注册时使用的用户名和密码。
3. 点击“登录”。若由报名或订单页面跳转而来，登录后会按页面跳转安排继续操作。

未登录时可浏览公开内容；报名、收藏和查看个人订单等操作需要先登录。登录过期后，请重新登录再继续。

### 3.3 退出

在提供“退出”入口的账号区域点击退出。使用公共设备结束操作后，应退出账号并关闭浏览器页面。

## 4. 搜索和筛选旅游线路

### 4.1 关键词搜索

1. 点击“搜索”。
2. 在搜索框输入目的地、线路或景点相关关键词。
3. 查看匹配的线路卡片，点击卡片进入线路详情。
4. 点击搜索框的清空图标可清除关键词；没有匹配结果时，可更换关键词或查看全部线路。

搜索页还提供热门目的地和线路分类入口，点击后可查看对应线路。

### 4.2 条件筛选

1. 点击“路线”，填写出发城市和目的地；需要时可使用交换按钮互换两者。
2. 按需要选择出游天数、出发月份。
3. 展开“价格范围与更多筛选”，输入最低价、最高价，点击“应用”。最低价不得大于最高价。
4. 如只想查看当前可预订的产品，勾选“仅显示有可报名团期的线路”。
5. 使用排序选项切换综合排序、价格从低到高、价格从高到低、报名人数或用户评分。
6. 点击线路卡片查看详情；有多页结果时使用分页控件翻页。

需要重新查找时，使用顶部重置图标“清空路线与筛选”。列表中的参考价格用于比较，最终应付金额以所选团期、人数及付款页订单摘要为准。

## 5. 浏览指南、地点和攻略

### 5.1 从指南查找地点

1. 点击“指南”，浏览推荐内容，也可通过城市、最新指南或发布者入口继续查找。
2. 点击一张指南卡片。地图聚焦该指南涉及的区域，内容面板显示指南介绍及地点列表。
3. 点击具体地点，进入地点详情。
4. 查看地点介绍、详细信息及可用的相关内容。
5. 在“途经此地点的线路”区域点击线路卡片，进入线路详情，查看团期并报名。

指南中的地点推荐不等于已包含在某个订单内。请在线路每日行程中确认实际途经地点，再选择团期。

### 5.2 阅读旅行攻略

在线路详情的攻略入口，或地点详情的“旅行攻略”区域，点击文章查看内容。攻略用于了解目的地，具体费用、住宿及服务安排请以线路详情、预订须知和订单信息为准。

## 6. 查看线路、团期及住宿

### 6.1 核对线路资料

打开线路详情后，建议依次查看：

- 线路名称、出发地、目的地及行程天数。
- 团期的出发与结束日期、成人价、儿童价及剩余名额。
- 每日行程、途经地点、交通、餐饮与住宿安排。
- 费用包含、费用不包含及预订须知。
- 已公开的用户评价。

如页面显示“暂无说明”或“待确认”，表示相应资料尚未提供完整，可先通过咨询功能了解，再决定是否报名。

### 6.2 选择团期

选择符合出行时间的团期后，核对底部显示的已选团期价格，再点击“立即报名”。已满或不可报名的团期无法继续提交；没有可报名团期时，可更换线路或稍后再查。

### 6.3 查看酒店与住宿说明

每日行程中的住宿可能显示为：已安排酒店、按住宿标准安排、不含住宿或住宿待确认。看到“住宿待确认”时，不应理解为已经确定酒店，也不等于不含住宿。

已关联且可公开查看的酒店可点击进入详情，查看地址、酒店介绍、设施、图片及已提供的入住／退房信息。酒店官方星级不等于游客评分；具体房型、早餐等安排应结合对应行程日的说明核对。

## 7. 填写报名信息

### 7.1 人数与联系人

1. 从线路详情点击“立即报名”，进入“填写报名信息”。
2. 填写成人和儿童人数，核对总人数。人数必须为非负整数，总人数至少 1 人，且不能超过当前可报名名额。
3. 填写联系人姓名及有效的 11 位手机号；需要时填写邮箱。
4. 在右侧或页面下方的“行程确认”区域核对团期、人数和费用。

### 7.2 每位出行人的资料

按页面显示的每一位出行人分别填写：姓名、性别、出生日期、证件类型、完整证件号码、紧急联系人及其电话；出行人联系电话按需要填写。姓名及证件号码应与实际出行证件一致。

可以从常用出行人中选择已有资料。当前报名页选择常用出行人后，仍需按提示补充完整证件号码；列表中的掩码号码不能作为报名证件号码提交。同一个常用出行人不能重复选择到本次订单的多个位置。

如常用出行人加载失败，可点击“重新加载”，也可手工填写本次报名资料。

### 7.3 提交报名

1. 有饮食、行动辅助等需求时，在“其他需求”中填写备注。
2. 核对所有资料后，点击报名页底部的提交按钮进入付款。
3. 系统会再次校验价格、团期状态和名额；校验不通过时，按提示返回选择团期或修改人数。

报名订单保存下单时的价格和出行人资料。之后修改常用出行人，不会自动修改已创建订单中的资料。

### 7.4 从付款页返回修改

从本次报名进入付款页后，点击返回可回到报名信息页，继续查看和编辑已填写的内容。若已有待支付订单，修改报名信息后再次提交，系统会提示取消原订单并重新下单；此时会重新校验价格和名额。

报名草稿保留在当前页面会话中。刷新页面、关闭页面或切换账号后，不保证能恢复未提交资料；已创建订单请在“我的订单”中查找。

## 8. 确认并付款

付款页为独立页面。进入“确认并付款”后，先核对线路、出行日期、人数、联系人和订单总额。

### 8.1 支付宝沙箱付款

1. 选择支付宝付款方式。
2. 点击“前往支付宝付款”。
3. 按沙箱收银台提示，使用项目演示环境提供的沙箱账号完成操作。
4. 返回系统后，在结果页查看付款状态，点击“查看订单详情”继续查看订单。

付款结果以系统确认的状态为准。若页面显示“正在确认支付结果”，可稍候或点击“立即刷新状态”；不要仅凭收银台跳转就认定报名完成，也不要立即重复创建订单。

若提示支付未配置或无法前往收银台，请联系项目演示负责人检查环境，普通用户无需填写支付密钥。

### 8.2 本地模拟支付（仅部分测试环境可见）

1. 若付款页显示“本地模拟支付”，可选中该方式。
2. 点击“确认模拟付款”。
3. 系统记录测试付款并进入结果页，订单变为“待确认”。

模拟支付不发生资金交易，付款记录会注明“本地模拟支付”。已经发起支付宝支付的订单不能改用该方式；模拟支付订单不支持支付宝退款。

### 8.3 暂时不付款

点击“稍后付款，查看订单”可进入订单详情。之后可从“我的订单”找到待支付订单，继续付款或取消订单。

**付款成功后还需要旅行社确认报名。** 只有订单进入“已确认”，才表示旅行社已完成报名确认。

## 9. 管理订单与查看行程

### 9.1 查找订单

1. 登录后进入用户中心，选择“我的订单”。
2. 按页面提供的状态分类筛选，或使用分页查找订单。
3. 点击“查看详情”进入独立的订单详情页。
4. 查看订单号、状态、联系人、价格与支付记录、出行人、退款记录等内容。

订单号是咨询和核对订单的重要依据。证件号码在普通展示中以掩码显示。

### 9.2 理解订单状态

| 页面状态 | 含义及下一步 |
|---|---|
| 待支付 | 已创建订单，可继续付款或取消 |
| 待确认 | 已支付，等待旅行社审核报名 |
| 已确认 | 报名已确认，可查看行程并等待出发 |
| 行程中 | 团期正在进行，可查看行程安排 |
| 已完成 | 行程已结束，符合条件时可发布评价 |
| 已取消 | 待支付订单已取消，不能继续对该订单报名 |
| 退款审核中 | 已提交申请，等待工作人员处理 |
| 退款处理中 | 退款正在处理或结果等待确认，查看退款记录了解进度 |
| 已退款 | 系统已确认退款完成 |

退款申请未通过时，查看退款记录中的审核意见；订单可能恢复为申请前的业务状态。订单状态与支付状态是不同信息，应结合订单详情中的记录理解。

### 9.3 查看每日行程

已确认、行程中或已完成的订单，在详情页提供“查看行程”按钮。点击后查看每日安排；加载失败时使用重试入口，需更新时点击“刷新行程”。

该入口展示当前线路的公开行程，不是历史行程快照。后续公开行程调整可能反映到这里，但不会改写订单中的下单价格或出行人快照。

## 10. 取消订单和申请退款

### 10.1 取消未付款订单

1. 在“我的订单”或订单详情找到待支付订单。
2. 点击红色描边的“取消订单”按钮。
3. 阅读弹窗，确认后执行取消；不想取消时关闭弹窗或选择取消操作。
4. 操作成功后，核对订单状态是否变为“已取消”。

取消后若想重新报名，需要重新选择团期创建订单，价格与名额以重新下单时为准。已支付订单应按退款流程处理。

### 10.2 申请退款

1. 打开符合退款条件的订单详情。当前入口适用于“待确认”或“已确认”，且没有正在审核或处理中的退款申请的订单。
2. 点击“申请退款”。
3. 填写 2–500 个字符的退款原因，点击“提交退款申请”。
4. 提交成功后，在订单详情的“退款记录”中查看申请及后续审核情况。

退款申请提交不等于退款完成。工作人员审核和退款处理后，状态才会更新。审核未通过时，阅读审核意见，必要时通过咨询沟通。

未显示退款按钮时，请先核对订单状态和已有退款记录。本地模拟支付订单不会提供支付宝退款入口；行程中或已完成订单也不提供本手册所述的在线申请入口。

## 11. 发布与查看评价

1. 在“我的订单”打开已完成订单，或从“我的评价”选择“去评价”。
2. 点击订单详情中的评价按钮。
3. 选择 1–5 星评分，填写 1–1000 个字符的体验内容。
4. 点击“发布评价”。成功后可在订单详情或“我的评价”查看。

每个符合条件的已完成订单只能提交一次评价。未完成的订单不能评价；已经评价的订单不会再次提供发布入口。请根据实际体验评价线路及服务，避免在评价中公开证件号码、电话等个人资料。

## 12. 管理个人资料和常用出行人

### 12.1 个人资料

1. 打开用户中心的“个人资料”。
2. 按需要修改昵称、真实姓名、手机号或邮箱。
3. 点击保存按钮，确认页面显示保存成功。

个人资料用于账号展示与联系；报名时仍应核对该订单的联系人和出行人资料。

### 12.2 新增常用出行人

1. 打开“常用出行人”，点击新增按钮。
2. 填写姓名、性别、出生日期、证件类型、完整证件号码、紧急联系人及其电话；联系电话按需要填写。
3. 点击“保存出行人”。
4. 在之后的报名页面中选择该资料，按提示补充并核对信息。

### 12.3 编辑与删除

点击某条资料的“编辑”可修改。编辑时证件号码不会以明文回填；不修改号码时可保留空白，如需更换则重新输入完整号码。点击“删除”并确认，可移除常用出行人。

编辑或删除常用出行人只影响该资料及后续使用，不会自动改写历史订单中的出行人信息。

## 13. 收藏、消息与咨询

### 13.1 收藏线路

1. 在线路详情点击收藏图标；未登录时先登录。
2. 进入“我的收藏”查看已收藏的线路，点击卡片打开详情。
3. 再次点击收藏图标，或在收藏列表点击取消收藏，可移除收藏。

收藏不占用团期名额，也不锁定价格。当前收藏功能面向旅游线路，本手册不提供自建指南的操作步骤。

### 13.2 阅读消息

1. 从“消息”入口进入消息列表。
2. 点击某条未读消息卡片，即可将该条标为已读，未读数量随之更新。
3. 勾选“只看未读”可筛选尚未阅读的消息。
4. 点击“全部已读”可批量标记当前账号的未读消息。

站内消息用于通知支付、报名确认、退款等进展。实际订单结果请进入订单详情核对，阅读通知本身不会执行付款或退款操作。

### 13.3 发起和跟进咨询

1. 打开用户中心的“咨询”。
2. 在“发起咨询”填写标题及问题描述，提交咨询。涉及订单时可注明订单号和具体问题。
3. 在“历史记录”找到咨询，点击“查看详情”，阅读问题及客服回复。
4. 问题处理完成后，在详情中点击“关闭咨询”，按提示确认。
5. 已关闭的咨询可在列表或详情中删除，删除前请确认是否仍需保留记录。

咨询采用留言与回复方式，不是即时聊天。提交后需等待工作人员处理。

## 14. 账号安全

1. 进入“账号安全”。
2. 输入原密码、新密码，并再次输入新密码。
3. 新密码须为 8–72 个字符，且 UTF-8 编码不超过 72 字节；含中文或表情时可能更早达到字节上限，请按页面提示调整。
4. 新密码不能与原密码相同，两次输入必须一致。
5. 提交成功后系统退出登录，使用新密码重新登录。

请妥善保管密码，不与他人共用账号。不要在咨询、评价或截图中公开密码、完整证件号码等敏感资料。

## 15. 常见问题

| 问题 | 处理方法 |
|---|---|
| 搜索不到线路 | 清空部分筛选，检查目的地、月份及价格范围，或换用关键词 |
| 找到线路但不能报名 | 查看是否已有开放团期、是否已满，以及所选人数是否超过剩余名额 |
| 团期还有名额，提交时却失败 | 提交时会再次核验库存，其他用户可能已占用名额；返回重新选择 |
| 常用出行人的证件号只显示部分字符 | 属于隐私保护；报名页按提示重新输入完整号码，不要输入带星号的掩码 |
| 在付款页返回后资料不见了 | 草稿只保存在当前会话中；刷新、关闭页面或切换账号可能丢失，先到“我的订单”检查是否已有订单 |
| 已在支付宝操作，但仍显示确认中 | 稍候刷新付款结果或订单详情，避免重复创建订单；持续异常时提供订单号咨询 |
| 支付成功却显示待确认 | 这是等待旅行社审核报名的状态，审核确认后才会显示“已确认” |
| 没有本地模拟支付选项 | 当前环境未开放该测试方式，按页面提供的方式操作 |
| 没有取消或退款按钮 | 可用操作取决于订单、支付及退款状态，先查看详情和退款记录 |
| 退款还在处理中 | 处理结果尚未确认，查看退款记录或发起咨询，不要将“处理中”当作已退款 |
| 无法发布评价 | 需订单已完成且尚未评价；已评价订单不能重复发布 |
| 页面突然要求重新登录 | 登录状态可能已失效，重新登录后再进入相应功能 |
| 酒店或地点资料不完整 | 以已展示资料为准，重要安排可通过咨询确认；暂无图片或说明不代表服务已确定 |

反馈问题时，建议提供发生时间、所在页面、操作步骤、错误提示以及相关订单号。截图前请遮盖个人敏感资料。
